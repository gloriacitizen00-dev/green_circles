# 🟢 Green Circles

## Data Visualization Through Digital Art and Creative Coding

Green Circles is a data visualization project that explores alternative ways of representing information through technology, movement, and visual forms.

Instead of presenting data only through traditional charts and graphs, this project investigates how information can become an interactive and visual experience. By using digital shapes, animation, and creative coding techniques, data can be transformed into a more intuitive and engaging form of communication.

---

## 🎨 Concept

Data is not only a collection of numbers; it is also a story that can be interpreted visually.

Green Circles explores how designers can use elements such as circles, movement, scale, position, and composition to create new ways of understanding information.

The circle becomes a visual language that can represent relationships, quantities, patterns, and changes over time. Through creative coding, students can experiment with different forms and develop their own methods of translating data into visual experiences.

---

## 🧠 Educational Approach

This project is designed from a digital design and creative technology perspective.

Students are encouraged to think beyond conventional data representation and explore questions such as:

- How can information be communicated through visual experiences?
- How can movement improve the understanding of data?
- How can shapes and composition create meaning?
- How can technology become a tool for artistic interpretation?

The objective is not only to display information, but to develop a creative process where students make design decisions based on exploration, intuition, and visual storytelling.

## ✨ Design Principles

Green Circles explores:

- **Visual communication:** transforming data into understandable visual elements.
- **Interaction and movement:** using animation to create dynamic representations.
- **Creative interpretation:** allowing multiple visual solutions for the same information.
- **Digital experimentation:** combining programming and design thinking.

---

## 🚀 Project Goals

The main goal of this project is to demonstrate how coding can become a creative medium for designers.

Through digital tools, students can move from simply reading data to experiencing it, creating visual systems that are informative, expressive, and meaningful.
