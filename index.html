Green Circles

Interactive Data Visualization

Word Frequency Visualization

This project explores the visualization of the 200 most frequently used words extracted from a Wikipedia article. The objective was to process the dataset using JavaScript and transform it into an animated visual composition.

Each moving circle represents one of the words found in the analysis. Rather than presenting the information as a traditional chart or table, the data is displayed as an interactive animation, offering a more engaging and modern way to communicate information.

One of the most exciting aspects of this project is that the concept can be expanded almost without limits. Different datasets, shapes, colors, animations, and interactions can be combined to create unique visual experiences, showing that data visualization can be both informative and artistic.
